<h1 align="center">Sabrity</h1>

<p align="center">
  App de estudos com IA: envie um PDF, DOCX, imagem (foto de mapa mental/anotação) ou link de uma aula/vídeo,
  e o Sabrity organiza o conteúdo por tópicos e gera resumo, mapa mental, flashcards e questões pra você estudar.
</p>

---

## ⬇️ Baixar

Pegue a versão mais recente na aba **[Releases](../../releases/latest)** deste repositório:

| Plataforma | Arquivo |
|---|---|
| 🖥️ **Windows** | `Sabrity Setup.exe` |
| 🤖 **Android** | `sabrity.apk` (ative "instalar de fontes desconhecidas" no Android pra instalar) |
| 🌐 **Web** | Acesse direto: **[sabrity-web.onrender.com](https://estudos-ia-web.onrender.com)** |

Não precisa configurar nada — os apps de desktop e Android já vêm prontos pra usar, sem pedir chave de API nem servidor local.

## O que o Sabrity faz

- **Resumo, mapa mental, flashcards e questões** gerados automaticamente a partir do seu material.
- **Aceita PDF, DOCX, imagem ou link de vídeo-aula** — inclusive fotos de mapas mentais/anotações manuscritas.
- **XP e streak** pra manter o ritmo de estudo, estilo Duolingo.
- **Banco de questões do ENEM** com mais de mil questões reais (2020–2025).
- **Turmas** para professores atribuírem listas de exercícios aos alunos.
- Perfis de estudo (ensino escolar, ENEM, universidade, concurso público) que ajustam o tom do material gerado.

## Sobre este repositório

Este repositório contém **apenas os instaladores prontos** para download — o código-fonte do Sabrity é privado.
